# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the `monorepo-starter` monorepo.

## What is an ADR?

An ADR captures a significant technical or architectural decision — the context that led to it, the decision itself, and its consequences. They are intentionally brief and written in plain language so both humans and AI agents can quickly orient to _why_ the codebase is the way it is.

## Naming Convention

Files are named with a zero-padded 4-digit sequence number followed by a short kebab-case title:

```
docs/adr/
├── README.md                          ← this file
├── 0001-short-decision-title.md
└── 0002-another-decision.md
```

## Statuses

- **Accepted** — The decision is active and in effect.
- **Deprecated** — The decision was once accepted but is no longer relevant.
- **Superseded by ADR-XXXX** — A newer ADR replaces this one; link to the replacement.

## Template

```markdown
# ADR-XXXX: Title

**Date**: YYYY-MM-DD
**Status**: Accepted

## Context

What situation or problem led to this decision?

## Decision

What did we decide?

## Consequences

What are the results of this decision? What becomes easier or harder?
```
